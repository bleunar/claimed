# Administrator Guide

Welcome to the Administrator Documentation. As an Administrator, you have full control over the system's configuration, users, and global inventory.

## Project Initialization

If you are setting up the system for the first time, follow these steps to get your organization ready:

1.  **Create Departments**: Go to **Departments** and add your organization's units (e.g., "College of IT", "Finance Office").
2.  **Assign Department Heads**: Head over to **Accounts**, create a new account for the leader of a department, and set their role to **Department Head**.
3.  **Define Locations**: For each department, add physical locations like Laboratories or Offices. This allows you to track where hardware is actually located.
4.  **Onboard Staff**: Create accounts for **IT Technicians** and **Lab Assistants** who will be doing the day-to-day inventory work.

## Key Capabilities

*   **Account Management**: Create, suspend, or delete any user account. You can also reset passwords if someone gets locked out.
*   **Department Oversight**: Monitor all departments and their assigned resources from a high-level view.
*   **Global Inventory Control**: View every piece of hardware in the system, regardless of which department "owns" it.
*   **System Configuration**: Manage the fundamental building blocks of the system, including locations and categories.

> **NOTE:** Use the **Search** and **Filter** tools on the Accounts and Components pages to quickly find exactly what you're looking for!
